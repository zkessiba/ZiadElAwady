# NovaTech Solutions — Lab 2

A four-page HTML/CSS company website created for a web development lab.

## Files
- `index.html` — Home page
- `about.html` — About page
- `products.html` — Product catalogue with a semantic HTML table
- `contact.html` — Contact form with browser validation
- `style.css` — Shared responsive styling

## Test locally
Open `index.html` in a browser. Use the navigation menu to visit all pages.

## Validate HTML
For each HTML file:
1. Open https://validator.w3.org/
2. Choose **Validate by File Upload** or **Validate by Direct Input**.
3. Upload/paste the HTML file contents.
4. Fix any errors the validator reports. Take a screenshot showing the clean result.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `lab2-company-website`.
2. Upload all four HTML files, `style.css`, and this README to the repository's root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/lab2-company-website/`.

## Important
This is a front-end student demo. The contact form uses native HTML validation but does not send messages because there is no server-side form handler. Product names and prices are fictional.
